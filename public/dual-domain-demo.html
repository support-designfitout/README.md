Integration Guide

How to Use Dual Domain Configuration

  1. Include domain-config.js in your HTML pages
  2. Listen for the domainConfigReady event
  3. Use window.domainConfig to access configuration
  4. Check features with isFeatureEnabled(featureName)
  5. Get settings with getSetting('path.to.setting')
